# CSC584 Individual Assignment 1: Personal Profile Web Application

## Description
A simple Personal Profile Web Application built using HTML, CSS, Java Servlet, and JavaServer Pages (JSP). The application collects user profile details via an HTML form, processes the data using HTTP POST in a Servlet, and displays the formatted profile on a JSP page.

## Technologies Used
- HTML5 & CSS3
- Java Servlet (HTTP POST)
- JavaServer Pages (JSP)
- Apache NetBeans / GlassFish or Apache Tomcat

## How to Run
1. Clone this repository:
   `git clone https://github.com/your-username/CSC584-Individual-Assignment-1.git`
2. Open the project in **Apache NetBeans** (or your preferred Java IDE).
3. Ensure a server (GlassFish or Apache Tomcat) is configured.
4. Right-click the project and select **Run**.
5. The browser will open `index.html`. Fill in the form and click **Submit Profile** to view the output on `profile.jsp`.
